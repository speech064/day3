# 제주 관광지 소개 페이지

공공 보고서(제주 관광시장 동향 보고서)를 참고해 제주 관광지 100곳의 데이터를 만들고, 이를 카드 형태로 보여주는 소개 웹페이지를 만든 과정과 결과물입니다.

## 폴더 구성

```
jeju/
├─ jeju.html              소개 웹페이지 (카드, 카테고리 버튼, 이름 검색, 가 보고 싶은 곳)
├─ jeju_spots.json        완성된 데이터 (100곳)
├─ README.md              이 문서
├─ 데이터제작/
│   ├─ spots_raw.txt          직접 고른 100곳 (이름|카테고리|설명|점수|키워드)
│   ├─ 1_build_data.ps1       보고서와 대조해 source 채우고, 중복·카테고리 검증 후 JSON 생성
│   ├─ wikimedia_images.js    위키미디어에서 사진 후보를 찾는 스크립트 (브라우저 콘솔용)
│   ├─ wikimedia_images.tsv   검토 후 채택한 사진 49개 (이름 / 파일명 / 작가·라이선스)
│   └─ 2_add_images.ps1       사진 정보를 JSON에 반영
└─ 참고자료/
    ├─ pdf/                   참고한 PDF 4개
    └─ 추출텍스트/            동향 보고서 3종에서 뽑은 텍스트
```

## 제작 과정

1. **자료 확인** – 처음 받은 F&B 분석 보고서는 외식 소비 통계라 관광지 목록이 없어서 쓰지 않았고, 제주 관광시장 동향 보고서(2026년 3월호·6월호·9월호)를 참고했습니다. 보고서가 스캔 이미지 위주라 pdf.js로 텍스트를 추출했습니다.
2. **관광지 선정** – 보고서의 월별 내비게이션 도착 순위(산·오름, 해변·해안, 숲·공원, 관광지·시장)와 비짓제주 검색 키워드 순위에서 자주 찾는 곳을 골라 100곳으로 맞췄습니다.
3. **데이터 작성** – 항목은 `name, category, description, score, selected, source`입니다.
4. **검증** – 이름 중복 0건, 카테고리 11개로 통일(예: 해변과 해수욕장을 따로 두지 않고 모두 "해변").
5. **웹페이지 제작** – 리츠칼튼 사이트의 분위기(중앙 로고, 가는 대문자 메뉴, 세리프 제목, 골드 포인트)를 참고했습니다.
6. **사진 추가** – 위키미디어(한국어 위키백과 대표 사진, Commons 파일 검색)에서 자유 라이선스 사진만 사용했고, 사진이 없는 곳은 색감 패널로 두었습니다.

## 데이터 기준

- **score** – 보고서 순위가 높고 여러 달에 걸쳐 나온 곳을 높게 준 상대 점수(0~100)입니다. 보고서에 없는 곳은 대표성을 기준으로 직접 매겼습니다.
- **selected** – score가 75 이상이면 `true` (21곳). 페이지의 "가 보고 싶은 곳"에 모아 보여줍니다.
- **source** – 이름이 확인된 보고서 이름. 보고서에 없는 26곳은 빈 문자열입니다.
- **image / image_credit / image_source** – 사진 주소, 작가·라이선스, 위키미디어 파일 페이지. 사진을 찾지 못한 51곳은 이 필드가 없습니다. 위키미디어 사진은 라이선스상 작가 표기가 필요해 카드에 함께 보여줍니다.

## 실행 방법

`jeju.html`은 `jeju_spots.json`을 `fetch`로 읽기 때문에 파일을 더블클릭해서 열면 동작하지 않습니다. 이 폴더를 웹 서버로 열어야 합니다. (예: VS Code의 Live Server, 또는 Vercel 같은 배포 서비스)

## 알아둘 점

- 설명 문구와 위치 정보는 일반 상식으로 쓴 것이라 공개 전에 검토가 필요합니다.
- 사진은 제주 관광공사(비짓제주) 사진이 아니라 위키미디어 사진입니다. 비짓제주 사진은 저작권이 제주관광공사에 있어 사용하지 않았습니다.
- 사진 주소는 위키미디어를 바로 불러오는 방식이라 인터넷 연결이 필요합니다.
- 데이터 제작 스크립트는 Windows PowerShell 5.1 기준으로 작성했습니다.
